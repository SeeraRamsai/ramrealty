# Ram Realty visual redesign

Implemented locally on 31 October 2026. No push or deployment performed.

The website now uses a warm-white, navy and teal consultancy design with the existing Ram Realty logo. All 15 HTML pages share navigation, a mobile menu, footer and mobile contact actions. The homepage prioritises four location guides, uses larger image-first project cards, and adds supplied-footage previews and a named consultant introduction. Project pages include walkthrough-still galleries, section navigation, light specification panels and redesigned enquiry forms. Location guides use a two-column reading and area-map layout on desktop and a single column on mobile.

Existing canonical URLs, project information, form fields, video behaviour and illustration disclosures are retained. The location pages remain guides rather than claims of available units within every locality.

## Maintenance

Edit `dist/assets/modern-realty.css` for the shared visual system, then run `python tools/inline-page-styles.py`. The stylesheet is applied last so the static pages share one design while retaining their existing form and video behaviour. Edit page markup directly for future content changes. `tools/redesign-site.py` is the one-time shell/homepage migration, not a complete site generator. Do not rerun the older `tools/add-location-guides.py` to update guide content: it predates this shared layout.
