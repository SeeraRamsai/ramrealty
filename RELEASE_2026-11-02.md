# Website release: 2 November 2026

This release publishes the light consultancy redesign, four locality guides and the prepared canonical redirect fixes. It preserves the existing project URLs, listing qualifications, form registration and deferred video behaviour.

## Source review

- The 13-URL sitemap includes Madhuravada, PM Palem, Yendada and Kommadi guides. The videos page modification date now reflects its substantive 31 October content update.
- Ordinary homepage/internal HTML links reach all 13 sitemap pages without JavaScript. Canonicals agree with sitemap destinations. The enquiry follow-up and missing-page documents remain `noindex`.
- Unique metadata, social previews, project structured data, breadcrumbs, actual listing localities, spelling aliases and price/area/charge consistency were checked. No unsupported inventory, review schema or artificial keyword pages were added.
- The three information-page 301 rules match between Netlify configuration and the publish directory. Genuine missing paths retain 404 handling.
- All four project forms retain their original field definitions and Netlify registration. No real enquiry was sent during release QA.

The MVV mobile blocking-time result remains a limitation. Its measured main-thread work is predominantly style/layout (about 1,589 ms); script evaluation is about 124 ms. Review found no synchronous layout reads or heavy initial work in the small enquiry handler. No speculative form/video rewrite was made. The earlier homepage result varied substantially with test conditions; the fresh score is not attributed to a source performance improvement. These are localhost lab samples, not production field Core Web Vitals. Google currently has insufficient Core Web Vitals usage data for the site.

## Remaining limitations

Supplied videos lack verified captions/transcripts and complete media alternatives. Automated accessibility scores do not establish full WCAG conformance. Google must recrawl published redirects and the expanded sitemap; publication does not guarantee indexing. A labelled production enquiry and notification-delivery test was not repeated.

Private screenshots, Search Console observations, before-release recovery copies and full audit JSON are retained under `audit-results/release-2026-11-02/` and are excluded from Git.
